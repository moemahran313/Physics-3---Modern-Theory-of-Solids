Physics 3: Modern Theory of Solids
An advanced, dual-track pedagogical engine for mastering the Theory of Solids through rigorous mathematical proofs and physical visualization. Developed for Physics 3 at Modern Academy.

🌟 Overview
This project serves as a comprehensive educational tool designed to bridge the gap between abstract mathematical concepts and tangible physical phenomena in solid-state physics. By providing a "dual-track" learning experience, it allows students and researchers to simultaneously explore rigorous derivations and interactive visual models.

✨ Features
Dual-Track Learning: Seamlessly switch between or combine mathematical rigor and physical intuition.

Rigorous Mathematical Proofs: Step-by-step breakdowns of complex solid-state theorems and equations.

Physical Visualization: Interactive models that bring crystal structures, band theory, and lattice vibrations to life.

Modern Pedagogical Engine: Built with modern web technologies for a fast, responsive, and engaging educational experience.

🛠️ Tech Stack
Based on the repository configuration, this project utilizes a modern TypeScript/Node environment:

TypeScript (Strongly typed backend/frontend logic)

Vite (Next-generation frontend tooling)

Bun (Ultra-fast dependency management and runtime)

Node.js/Express (Custom server via server.ts)

🚀 Getting Started
Prerequisites
Make sure you have Bun installed on your local machine.

Installation
Clone the repository:

Bash
git clone https://github.com/moemahran313/Physics-3---Modern-Theory-of-Solids.git
cd Physics-3---Modern-Theory-of-Solids
Install dependencies:

Bash
bun install
Set up environment variables:
Copy the example environment file and configure it as needed.

Bash
cp .env.example .env
Run the development server:

Bash
bun run dev
(Or check package.json for specific run scripts like bun run server.ts)

📂 Project Structure
/src - Core application source code and pedagogical modules.

/public - Static assets and visual resources.

/scripts - Automation and build scripts.

server.ts - Main entry point for the backend/development server.

vite.config.ts - Configuration for the Vite bundler.
