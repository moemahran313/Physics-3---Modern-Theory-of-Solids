# Physics 3 (ELCn114) Modern Theory of Solids — Engineering Recovery Prompts
## Architecture Overhaul & System Revival Plan

This directory contains production-grade, battle-tested engineering prompts specifically created to diagnose, redesign, and permanently resolve the four critical failure points of this application:

1. **Testing Engine** (`01_TESTING_ENGINE_OVERHAUL.md`): Clunky inputs, rigid string checks, no partial credit, unpausable timer, absence of step-by-step diagnostic feedback.
2. **Flashcards & Active Recall** (`02_FLASHCARDS_SPACED_REPETITION_OVERHAUL.md`): Superficial flipping, no true Leitner / SM-2 spaced repetition scheduling, missing keyboard ergonomics, lack of formula fill-in (cloze) mode.
3. **LaTeX & Mathematical Rendering** (`03_LATEX_MATH_ENGINE_UPGRADE.md`): KaTeX parsing crashes, unescaped delimiters, formula line wrapping cutoffs, unrendered math formulas, lack of copyable LaTeX.
4. **UI/UX & Aesthetic Slop Elimination** (`04_UI_UX_AESTHETIC_REJUVENATION.md`): Visual noise, nested container borders, cluttered pill badges, illegible dark-on-dark contrast, poor mobile layout.
5. **Master System Orchestrator** (`05_MASTER_SYSTEM_ORCHESTRATION.md`): Single mega-prompt synthesizing all four pillars into an authoritative execution run.

- **In AI Studio / Claude / GPT**: Copy the text from any of the `.md` files or copy them directly using the in-app **Prompt Directory & Studio** tab.
